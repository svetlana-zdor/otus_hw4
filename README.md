# Реализация локальной RAG-генерации на Python 3

Данный проект содержит практическую реализацию RAG-системы (Retrieval-Augmented Generation) на базе локальной языковой модели **Qwen 2.5** и векторной базы данных **ChromaDB**.

## Архитектура проекта

1. **Генерация базы знаний (`generate_dataset.py`):** Запрашивает у локальной LLM 10 фактологических заметок (~100 слов каждая) по теме «История освоения космоса» и сохраняет их в `dataset.json`.
2. **Индексация данных:** Создает эмбеддинги текстов через модель `nomic-embed-text` и заносит их в ChromaDB.
3. **RAG-генерация (`rag_generator.py`):** Принимает вопрос пользователя, выполняет семантический поиск релевантных контекстов в ChromaDB и передаёт найденные фрагменты в `qwen2.5` для формирования ответа.

## Быстрый старт

### 1. Развертывание Ollama в Docker

Запустите контейнер Ollama и скачайте необходимые модели (`qwen2.5` и `nomic-embed-text`):

```bash
# Запуск контейнера
docker run -d -v ollama:/root/.ollama -p 11434:11434 --name ollama ollama/ollama

# Скачивание генеративной модели и модели эмбеддингов
docker exec -it ollama ollama pull qwen2.5
docker exec -it ollama ollama pull nomic-embed-text
